# Phase 1 — Foundation · Lesson Map

The realistic breakdown of Phase 1 into fixed ~3-hour lessons. The **block stays 3 hours; the lesson count flexes.** Lessons are numbered generically (1.1, 1.2, …) and wired into the site with no fixed dates — the team sets dates as it goes.

This map supersedes the old "6 meetings" framing in `RANGER_Phase1_Plan.pdf` (the themes and exit criteria there still hold; only the lesson count changed).

## The 12 lessons

| # | Lesson | Focus | Artifacts |
|---|---|---|---|
| 1.1 | Kickoff | Form the company, six roles, safety ritual, outreach log | ✅ built |
| 1.2 | Soldering Bootcamp | Safety, the three joints, the five moves, hands-on until every kid is steady | rebuild (split from old 1.2) |
| 1.3 | Kit Unboxing & First Electronics | Inventory, build-sequence read, first kit joints, open the 3 records, capsule sketches | rebuild (split from old 1.2) |
| 1.4 | Electronics Workshop | Multimeter, switches, simple circuits + lab, the Electrical Symbols handout | rebuild (split from old 1.3) |
| 1.5 | Control Box I | Practice board + start the REV 4 build, meter-checking as you go | rebuild (split from old 1.3) |
| 1.6 | Control Box II | Finish wiring, power wire, tether, fuse, meter-check before power-up | rebuild (split from old 1.3) |
| 1.7 | Capsule Build & First Splash | Build the capsules, pool safety, every kid in the water, capsule drop #1 | rebuild (split from old 1.3) |
| 1.8 | Build & Iterate I | Assemble the Triggerfish frame, thrusters, tether | new |
| 1.9 | Build & Iterate II | Pool ops, tether handling, capsule dive #2 — diagnose every leak | new |
| 1.10 | Pilot & Validate I | Buoyancy, trim, every kid pilots | new |
| 1.11 | Pilot & Validate II | Capsule dive #3 (gate: 3 consecutive dry dives), troubleshooting + first SID | new |
| 1.12 | Showcase & Launch Phase 2 | Demo for sponsors, retrospective, Phase 2 preview, thank-yous | new |

*A holiday off-week sits between 1.7 and 1.8 — with flexible dates, it's just a gap, not a fixed week.*

## Phase 1 exit gate (unchanged)

Company formed with the safety ritual running unprompted; every kid soldered and in the water (by 1.7); the Triggerfish built and piloted by every member; capsules pass three consecutive dry dives (1.11); pool access locked including the deep-water host; notebook/photo/outreach logs running; admin track underway with named owners.
